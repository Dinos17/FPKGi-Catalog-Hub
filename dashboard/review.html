This dashboard reads sanitized reports generated by the private Mocha scanner. The Mocha API key is never sent to this public website. Inventory data is metadata-only: file names, folders, sizes, upload dates and platform classifications. File IDs, API paths, download links and checksums are not published. Possible duplicates are review candidates only; automatic deletion is disabled. Previous inventory versions may remain accessible in this public repository’s Git history even after a newer report removes their metadata.
